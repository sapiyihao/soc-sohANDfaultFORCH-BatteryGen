# DNN-MTL：物理感知深度多任务联合估计网络

> **D**eep **N**eural **N**etwork for **M**ulti-**T**ask **L**earning
> 面向马钢混动机车 8 支路并联电池组的 SOC / SOH 联合估计（纯深度学习方案）
> 状态：设计阶段 | 最后更新：2026-07-15 | V1.3：层级特定约束 + Star Operation + 不确定性自适应加权

---

## 0. 与 AEF-GPR 的定位对比

| | AEF-GPR | DNN-MTL（本方案） |
|---|---|---|
| 核心哲学 | 物理方程驱动 + 统计辅助 | 数据驱动 + 物理损失约束 |
| SOC 估计频率 | 10Hz（EKF 每 100ms 迭代） | 10Hz（滑动窗口每 100ms 推理） |
| SOH 更新时机 | 每个充电片段修正一次 | 仅在充电时更新，放电时冻结 |
| 物理约束形式 | **硬约束**（EKF 状态方程） | **软约束**（损失函数惩罚项） |
| 模块关系 | 独立训练，推理串联 | **端到端统一训练** |
| 可解释性 | 高（每个状态对应物理量） | 低（黑盒特征） |
| 数据需求 | 少（GPR 小样本友好） | 多（深度网络需要大量标注） |
| 部署难度 | 低（EKF+递归GPR，~162KB） | 较高（需ONNX/TensorRT优化） |

## 1. 总体架构

### 1.1 推理模式：滑动窗口实时输出

```
CAN 总线每 100ms 一帧数据进入系统（10Hz）：

时刻 t 的推理：
  输入：过去 W=128 个采样点的 V/I/T 序列（覆盖约 2 分钟，不区分充放电）
       + SOH 锚点（最近一次充电时估计的 SOH 值）
       + 工况标记（当前是充电/放电/静置）
  ↓
  网络前向传播一次（~10ms）
  ↓
  输出：SOC(t), SOH(如果是充电), 不确定性(t)

下一帧：窗口向前滑动 1 步，重复推理
```

**关键设计决策**：

> **SOC 实时化**：将输入从"完整充电片段"改为"滑动窗口"，窗口长度 W=128 覆盖约 2 分钟数据，不区分充放电。每 100ms 窗口向前滑一步，推理一次。这样 SOC 在充电、放电、能量回收、静置等所有工况下都能持续输出。
>
> **SOH 只在充电时更新**：SOH 是慢变量，物理上不会在几秒内变化。放电时 SOH 头不更新（冻结上次充电时的估计值），只在检测到有效充电片段时输出新的 SOH 估计。这符合物理规律，也避免了放电时用不完整信息做不可靠的 SOH 推断。
>
> **SOH 锚点回路**：最近一次充电时估计的 SOH 值作为第 2 路输入的一部分反馈回网络。这样 SOC 头的推理就能利用最新的容量信息（和 AEF-GPR 中 SOC 分母用 SOH 做容量基准的逻辑等价，但这里是隐式学习）。

## 2. 详细架构设计

### 2.1 数据预处理管线

从 CAN 总线原始帧到模型输入张量的完整处理流程：

```
CAN 总线（每 100ms 一帧）
  ↓
Step 1: 字段提取与校验
  ↓
Step 2: 滑动窗口管理
  ↓
Step 3: 缺失值与异常值处理
  ↓
Step 4: Z-score 归一化
  ↓
Step 5: 工况识别
  ↓
Step 6: SOH 锚点更新
  ↓
模型输入：时序张量 [batch, 128, 6] + 上下文向量 [batch, 5]
```

---

#### 2.1.1 Step 1: 字段提取与校验

从 CAN 报文中提取每支路的原始值，做基本合法性检查：

```
每支路（BMS3~BMS8）提取 6 个时序通道：

| 通道 | 协议字段 | 单位 | 有效范围 | 备注 |
|------|---------|------|---------|------|
| V总 | uiBMS3SumVolt | mV | 0 ~ 4500·N_cell | 零值 = 通信中断 |
| Vmax | uiBMS3HighestCellVolt | mV | 2500 ~ 4500 | 超出 = 传感器故障 |
| Vmin | uiBMS3LowestCellVolt | mV | 2500 ~ 4500 | Vmin > Vmax = 通道错位 |
| I总 | uiBMS3SumCurr | mA | -500A ~ +500A | 符号：正=放电，负=充电 |
| Tmax | uiBMS3HighestTemp | 0.1℃ | -40 ~ +85 | 超出 = 传感器故障 |
| Tmin | uiBMS3LowestTemp | 0.1℃ | -40 ~ +85 | Tmin > Tmax = 通道错位 |

校验规则：
  · 生命信号 usBMS3LifeSignal 连续 3 帧不变 → 通信中断，该帧标记为缺失
  · 支路外总压 uiBMS3OutSumVolt 与内总压 uiBMS3SumVolt 差值 > 5% → 接触器状态异常，该帧降权
  · AB 通道一致性标志位触发 → 该帧电压/电流使用 A/B 通道均值
```

---

#### 2.1.2 Step 2: 滑动窗口管理

每支路维护一个 W=128 的环形缓冲区，每 100ms 推入新一帧：

```
初始化（冷启动，模型刚上电）：
  缓冲区为空 → 第一帧数据复制 128 份填满整个窗口
  → 前 128 帧逐步用真实数据替换副本
  → 冷启动期间（前 12.8 秒）SOC 输出带"预热中"标记，置信度降低

正常运行：
  新一帧到达 → 推入环形缓冲区头部 → 最旧一帧被覆盖
  → 缓冲区始终保留最近 128 帧（约 2 分钟）

多支路同步：
  8 条支路的 CAN 报文可能不同步（±1 帧偏差）
  → 以 CCU2BMS_格林威治标准时间 对齐各支路的时间戳
  → 对齐后统一推入各自的环形缓冲区
```

---

#### 2.1.3 Step 3: 缺失值与异常值处理

```
缺失值（CAN 丢帧）：
  连续缺失 ≤ 3 帧 → 前向填充（复用上一帧的值）
  连续缺失 > 3 帧 → 线性插值（首尾有效帧之间）
  连续缺失 > 30 帧（3 秒）→ 标记"通信中断"，该支路冻结输出
    
异常值（传感器尖峰）：
  当前值偏离前后各 3 帧中位数 > 5×MAD（中位数绝对偏差）
  → 判定为尖峰，替换为该中位数值
  → 同时在异常统计中记录尖峰频率

物理不可能值：
  |I| 在 CCU2IDU_地面充电工况=0 时突增到 > 100A → 传感器故障
  Vmax < Vmin → 通道标记错误，交换后重新校验
  Tmax - Tmin > 30℃（同一支路内）→ 温度传感器异常
```

---

#### 2.1.4 Step 4: Z-score 归一化

```
每个通道独立归一化：
  x_norm = (x_raw - μ_ch) / σ_ch

μ_ch, σ_ch 在训练集上统计一次，推理时固定不变。

各通道典型统计量（示意，实际值取决于电池规格）：
  V总：     μ ≈ 3500·N_cell mV,  σ ≈ 200·N_cell mV
  Vmax：    μ ≈ 3600 mV,         σ ≈ 150 mV
  Vmin：    μ ≈ 3400 mV,         σ ≈ 150 mV
  I总：     μ ≈ 0（充放电均值为 0）, σ ≈ 50A
  Tmax：    μ ≈ 35℃,             σ ≈ 15℃
  Tmin：    μ ≈ 30℃,             σ ≈ 15℃

温度补偿：
  T 通道归一化前不做特殊补偿，网络通过 TCN 学习温度对电压的非线性影响。
  OCV-SOC 曲线中温度因子 T_c 在 L_consistency 计算时独立查表。
```

---

#### 2.1.5 Step 5: 工况识别

```
根据协议标志位和电流判断当前工况：

  CCU2IDU_地面充电工况=1    → mode=1（充电）
  CCU2IDU_混动工况=1 且 I>0  → mode=0（放电/驱动）
  CCU2IDU_混动工况=1 且 I<0  → mode=0（能量回收，仍为放电方向）
  |I| < I_rest（如 2A）持续 > 10s → mode=2（静置）

mode 的作用：
  · SOH 头仅在 mode=1 时输出新值（放电/静置时冻结）
  · SOC 头在所有 mode 下持续输出
  · 不确定性估计在所有 mode 下持续输出
```

---

#### 2.1.6 Step 6: SOH 锚点维护

```
SOH_anchor 是馈入上下文编码器的关键特征，代表"最近一次可靠 SOH 估计值"。

初始化：
  部署初期无充电片段 → SOH_anchor = usBMS3SOH（BMS 自带 SOH，作为初始值）

更新时机（仅充电模式）：
  每次有效充电片段结束后，网络输出新的 SOH_pred：
    SOH_anchor ← 0.95 × SOH_anchor + 0.05 × SOH_pred（指数移动平均，τ≈20 次充电）
  → EMA 平滑避免单次估计噪声导致锚点跳变
  → 相邻两次充电片段之间 SOH_anchor 保持不变

退化为 BMS SOH 的情况：
  若连续 30 天无有效充电片段 → SOH_anchor 缓慢向 BMS SOH 靠拢（混合权重从 1.0 线性衰减至 0.5）
```

#### 2.1.7 模型输入汇总

```
第1路：滑动窗口时序
  来源：Step 4 归一化后的环形缓冲区
  形状：[batch, 128, 6]
  其中 batch = 支路数（推理时 8，训练时 64×8）

第2路：SOH 锚点 + 工况上下文

    · SOC_BMS ∈ [0, 1]            ← usBMS3SOC，BMS 自带值（弱参考）
    · T_ambient ∈ [-1, 1]         ← CCU2IDU_环境温度，Z-score 归一化

```

### 2.2 TCN 时序编码器

```
TCN（Temporal Convolutional Network）：
  · 4 层空洞因果卷积，膨胀率 [1, 2, 4, 8]
  · 每层 64 通道，kernel_size=5
  · 每层后接 BatchNorm + GELU 激活
  · 残差连接
  → 输出：[batch, 128, 64]

全局平均池化（沿时间维度）：
  → 输出：[batch, 64]

再加一层 FC 扩维：
  FC(64→128) + LayerNorm + GELU
  → 时序特征向量：[batch, 128]
```

### 2.3 上下文编码器

```
MLP：
  FC(5→32) + LayerNorm + GELU
  FC(32→64) + LayerNorm + GELU
  → 上下文特征向量：[batch, 64]
```

### 2.4 融合层

```
Concat：[时序特征(128), 上下文特征(64)] → [batch, 192]
FC(192→256) + LayerNorm + GELU
Dropout(0.1)
→ 共享特征 Z ∈ [batch, 256]
```

### 2.5 层级特定约束：浅层出口 vs 深层出口

两个分支从编码器**不同深度**取特征——遵循"快慢变量"分配原则：

| 特征出口 | 来源 | 语义层次 | 给谁 | 理由 |
|---------|------|---------|:--:|------|
| **浅层 Z** | 交叉注意力之前 | TCN+上下文+嵌入融合，保留局部时序细节 | SOC 分支 | SOC 是快变量，需要感知秒级充放电波动 |
| **深层 Z'** | 交叉注意力之后 | 8 条支路互相对比后的全局特征 | SOH 分支 | SOH 是慢变量，支路间对比捕捉的退化模式远丰富于单支路波形 |

两个分支在各自第一层 FC 输出（均为 128 维）处通过 Star Operation 汇合，实现结构级物理乘积耦合。**与 V1.2 的关键区别**：SOC 分支的输入来自 Z（浅层），SOH 分支的输入来自 Z'（深层），而非两者都从 Z' 出发。

**Star Operation**：

```
F_soc [128] ← SOC分支 FC(256→128) 输出（输入来自浅层 Z）
F_soh [128] ← SOH分支 FC(256→128) 输出（输入来自深层 Z'）

F_star = (F_soc ⊙ F_soh) → FC(128→128) + GELU
F_soc' = F_soc + F_star    （残差注入 SOC 分支）
F_soh' = F_soh + F_star    （残差注入 SOH 分支）

各自 FC(128→64→1) → SOC / SOH
```

**物理直觉**：SOC 从浅层取特征 → 对瞬时充放电变化敏感；SOH 从深层取特征 → 8 条支路经过交叉注意力互相对比后，SOH 分支接收到的信号包含了支路间退化差异，比单支路波形丰富得多。逐元素乘法在中间层连接两个不同深度的特征——浅层的"当前状态"与深层的"长期趋势"的乘积交互，恰好对应电池物理中的 `ΔSOC · SOH`。

不确定性通过 MC Dropout 获得——推理时 T=20 次前向，取标准差为 ±σ。

## 3. 8 支路并联架构

第 2 节描述的是单支路网络结构。本节将其扩展为 8 支路并联处理架构——共享编码器提取通用特征，支路嵌入捕获个体差异，交叉注意力实现支路间对比与异常检测。

### 3.1 设计约束

```
8 条并联支路（BMS3~BMS8），每条独立上报 V/I/T，同为 10Hz。

共性：
  · 相同电芯化学体系 → 电压响应、OCV 曲线、退化模式共享
  · 相同工况（同时充电/放电）→ 外部条件一致

差异：
  · 老化速度不同 → SOH 逐支路分化（更换过电芯的支路 SOH 明显高于其他）
  · 负载分配不均 → SOC 可能有 2~5% 的支路间偏差
  · 异常通常单支路先发 → 支路间对比是异常检测的关键信号
```

### 3.2 架构选择：为什么不走 8 个独立模型

| 方案 | 参数量 | 交叉支路信息 | 异常检测 | 评估 |
|------|:--:|:--:|:--:|------|
| A. 8 个独立单支路模型 | 8 × 1.2M = 9.6M | 无 | 间接（后处理比较） | 浪费参数，支路间无法互相学习 |
| B. 单模型直接输入 8×6=48 通道 | ~3M | 隐式（网络内部） | 不透明 | 输入维度爆炸，8 倍时序长度难以训练 |
| **C. 共享编码器 + 支路嵌入 + 交叉注意力** | **~0.6M** | **显式（注意力机制）** | **可解释（注意力权重）** | **✅ 选定方案** |

### 3.4 共享时序编码器

```
同一套 TCN 权重处理所有 8 条支路的时序数据：
  · 输入：8 × [128, 6]（batch=8，并行前向传播）
  · TCN 结构：与 §2.2 完全相同（4 层空洞因果卷积，膨胀率 [1,2,4,8]）
  · 输出：8 × [128] 时序特征向量

共享的原因：
  · 电芯化学体系相同 → 电压响应的时间模式相同
  · 退化导致的变化是"量"的差异（幅值、斜率），不是"质"的差异（模式）
  · 共享权重相当于对所有支路的数据做联合训练，每个支路的数据都在训练同一个 TCN
```

### 3.5 支路嵌入

`E ∈ R^{8×32}` 是一个可学习的参数矩阵——8 行对应 8 条支路位置，每行是一个 32 维向量。本质上是 `nn.Embedding(8, 32)`，和网络其他权重一样通过反向传播训练。

**前向过程**：支路 i 的数据到达 → 查表取 `E[i]`（32 维）→ 拼入特征向量 → 送入后续层。

**训练过程**：训练数据可能来自多个电池包（多台同型号机车）。所有包的支路3数据都更新同一行 `E[3]`——梯度取的是跨包的"最大公约数"。这决定了嵌入编码的不是某个具体电芯的个体偏置，而是**支路位置角色的共性特征**。

**嵌入编码的是位置角色，不是个体身份**：

| 编码内容 | 来源 | 举例 |
|---------|------|------|
| 支路3 = 左前位置 → 散热好、线束阻抗偏高、负载轻 | 设计决定，所有同型号车一致 | 所有机车支路3的位置角色相同 |
| 支路8 = 右后位置 → 散热差、线束长、负载重 | 同上 | 所有机车支路8的位置角色相同 |
| 某支路传感器偏 +5mV | **不编码在嵌入中** | 个体差异，每台车不同 |
| 某支路老化更快 | **不编码在嵌入中** | 个体差异，随使用历史分化 |

个体差异通过两条通道处理：① **上下文编码器**中的 SOH_anchor 为每个支路提供当前老化状态锚点；② **TCN** 从 128 帧波形中直接感知（电压整体偏高 = 传感器偏置，内阻增大 = 老化加速）。

**跨包训练的梯度行为**：

```
训练数据来自机车A和机车B，各自支路3传感器偏置不同：
  机车A支路3: 偏置 +5mV
  机车B支路3: 偏置 -3mV

如果嵌入试图编码偏置 → E[3] 收到矛盾梯度 → 震荡不收敛
实际上嵌入学到的: 支路3在"左前位置"→ 散热条件好 → 温度偏低 →
  同样的电流下极化电压偏小 → 这是位置角色的物理共性，跨包一致
```

**为什么不用 one-hot**：one-hot 的 8 个向量互相正交（余弦相似度 = 0），网络无法表达"支路3 和支路6 位置角色对称、散热条件接近"——这是一个纯静态的 ID 标记。嵌入的可学习性允许网络发现位置角色之间的相似性，并支持换电芯场景：将 `E[5]` 重新随机初始化即可，其他 7 行不受影响。

```
训练收敛后（跨包训练）：
            E[3] ·
                  · E[6]    ← 位置角色对称（都是侧边支路），余弦距离近
     E[5] ·
                     
              · E[8]        ← 右后角落，散热最差，嵌入在另一个区域
    E[4] ·
                  
         · E[7]              ← 与E[8]位置相邻，嵌入也靠近
```

**推理时的行为**：部署后嵌入矩阵冻结为常量，不做在线更新。嵌入编码的位置角色共性对同型号车零成本复用——部署到新车时直接使用训练好的嵌入，无需微调。长期维护（年尺度）仅需离线定期更新。

### 3.6 支路上下文编码器

```
每个支路有独立的上下文（§2.3）：
  · SOH_anchor：各支路不同（不同老化程度）
  · mode：充电/放电/静置（同一时刻 8 条支路相同）
  · mileage：全车共享
  · SOC_BMS：各支路 BMS 自带 SOC
  · T_ambient：全车共享

共享上下文编码器（FC(5→32) + FC(32→64)）：
  → 8 × [64] 上下文特征向量

共享原因：上下文特征的语义是通用的（"SOH 低意味着容量小"），不需要每个支路学一套。
```

### 3.7 支路特征拼接与投影

```
每个支路独立拼接：
  z_i = Concat(TCN_feat_i[128], ctx_feat_i[64], E_branch[i][32])
      → [224]

共享投影层：
  FC(224→256) + LayerNorm + GELU + Dropout(0.1)
  → 8 × [256] 支路特征向量

共享的原因：投影操作是通用的维度变换，不包含支路特定逻辑。
支路特定信息已通过嵌入向量（E_branch[i]）注入。
```

### 3.8 交叉支路自注意力（核心创新）

```
将 8 条支路的特征堆叠为序列：
  Z = [z_1; z_2; ...; z_8] ∈ R^{8×256}

多头自注意力（4 头，每头 64 维）：
  Q = Z·W_Q,  K = Z·W_K,  V = Z·W_V     ← 所有支路共享投影矩阵
  Attention(Q,K,V) = softmax(QK^T/√d_k)·V

  Z' = LayerNorm(Z + Attention(Z))        ← 残差连接
  Z'' = LayerNorm(Z' + FFN(Z'))            ← 前馈网络

输出：8 × [256]（每个支路融合了其他 7 条支路的信息）
```

**为什么交叉注意力对 8 支路场景至关重要**：

```
① 支路间信息共享——通过对比增强估计：
  若支路 5 的 SOC 估计为 72%，其余 7 条支路在 65~68%：
  → 支路 5 的 Query 与其余支路的 Key 相似度低
  → 注意力权重集中在自身（"和其他人都不一样"）
  → 提示该支路可能存在异常偏差

② 信息共享——老化模式相似的支路互相增强：
  支路 3 和支路 6 的 SOH 退化轨迹相似：
  → 两者的 Key/Query 相似度高
  → 注意力权重互相增强
  → 两者共享统计强度，SOH 估计更稳定

③ 抑制单支路噪声：
  某支路传感器瞬时噪声 → 其特征向量偏离群体 →
  交叉注意力自动降低该支路对全局特征的影响 →
  该支路自身的估计仍受影响（无法完全消除），但不会污染其他支路
```

### 3.9 支路级输出分支

```
8 条支路共享同一套分支权重（SOC 和 SOH 各有一套独立参数）：

SOC 分支（共享权重，8 支路 batch=8 并行）：
  FC(256→128) + GELU + Dropout(0.2)
  FC(128→64) + GELU
  FC(64→1) + Sigmoid
  → 8 × SOC ∈ [0, 1]，每 100ms 全工况输出

SOH 分支（共享权重，与 SOC 分支结构相同，独立参数）：
  → 8 × SOH ∈ [0, 1]
  → 训练时：各支路独立判断 mode，仅充电窗口参与损失
  → 推理时：仅充电时更新，放电时冻结

不确定性（MC Dropout）：
  推理时 T=20 次前向，对 SOC/SOH 各支路独立计算 σ
  → 8 × {σ_SOC, σ_SOH}
```

### 3.10 Pack 级聚合

```
从 8 条支路输出聚合为 Pack 级指标：

SOC_pack = Σ(w_i · SOC_i) / Σw_i
  权重 w_i = SOH_i（健康支路权重更高）
  同时输出 SOC_min = min(SOC_i)，SOC_max = max(SOC_i)
  → 若 max-min > 5%：触发支路不一致警告

SOH_pack = min(SOH_i)
  木桶原则：最差支路决定 Pack 整体健康度
  同时输出 SOH_spread = max(SOH_i) - min(SOH_i)
  → 若 spread > 15%：建议检查/更换落后支路

Pack 级不确定性：
  σ_SOC_pack = √(Σ(w_i² · σ²_SOC_i) / Σw_i²)
```

### 3.11 交叉支路一致性损失

```
新增训练损失——鼓励网络检测支路间不一致性：

L_cross_consistency = (1/N) · Σ_i |SOC_i - median(SOC_1...SOC_8)|

  · 不强制所有支路 SOC 完全相同（负载分配确实有差异）
  · 但离群支路会受到惩罚
  · 正常时各支路 SOC 差异 < 3%，此损失接近 0
  · 某支路传感器异常导致 SOC 跳变 → 损失骤然增大 → 梯度推动 SOC 头修正

总训练损失（每条支路）：
  L_branch = L_SOC + L_SOH + L_physics + L_consistency + L_monotonicity

总损失（8 支路 + Pack 级）：
  L_total = (1/8)·Σ_i L_branch_i + λ_cross · L_cross_consistency

其中 λ_cross = 0.05（弱约束，因为正常时支路间确有合理差异）
```

### 3.13 推理流程（每 100ms）

```
Step 1: 数据接入
  8 条支路的当前帧 V/I/T 进入系统
  各自拼接为 [128, 6] 滑动窗口（复用前 127 步的历史数据）

  共享上下文编码器：batch=8

Step 3: 交叉注意力（~2ms）
  8×256 矩阵进入 Multi-Head Self-Attention
  输出 8×256 交叉感知特征

Step 4: 各头发散（~3ms）
  SOC/SOH 两头并行（batch=8）
  输出 8 组支路级结果

Step 5: Pack 聚合（~0.5ms）
  加权平均、min/max、支路偏差检测

Step 6: MC Dropout（可选，每 10 帧执行一次）

```

## 4. 物理约束损失函数（核心创新）

### 4.1 总损失

```
L_total = L_task_weighted + 0.1·L_physics + 0.05·L_consistency + 0.01·L_monotonicity
```

其中 `L_task_weighted` 的权重由可学习参数自动调节（见 §4.2），其余三项保持固定权重——它们是物理先验，不应被数据驱动的不确定性缩放。

### 4.2 任务损失 + 不确定性自适应加权

```
L_SOC = Huber(SOC_pred, SOC_label)
L_SOH = Huber(SOH_pred, SOH_label)          ← 仅充电窗口计算

# 不确定性自适应加权（替代手动 α=1.0, β=0.5）
σ_soc = exp(log_sigma_soc)                  ← 可学习参数，初始 σ=1
σ_soh = exp(log_sigma_soh)

L_task_weighted = L_SOC/(2·σ_soc²) + L_SOH/(2·σ_soh²) + log(σ_soc) + log(σ_soh)
```

**工作原理**：SOH 标注稀疏、噪声大 → L_SOH 原始值偏高 → 梯度推动 σ_soh 增大 → 1/(2σ²) 自动降低 SOH 权重。log(σ) 正则项防止 σ 无限增长。全程无需手动调整 α/β。两个 σ 在网络中仅增加 2 个 float32 参数。

### 4.3 物理耦合损失 L_physics（训练时仅在充电窗口生效）

#### 4.3.1 原始形式与循环依赖风险

原始设计中 L_physics 的形式为：

```
ΔSOC_pred = SOC_pred(t2) - SOC_pred(t1)        ← 网络输出
ΔSOC_phys  = η·∫I·dt / (SOH_pred · C_nom)      ← 也含网络输出 SOH_pred
L_physics  = Huber(ΔSOC_pred, ΔSOC_phys)
```

**风险**：两个比较项都来自网络输出。若 SOC_pred 和 SOH_pred 同时偏差但保持"自洽"（例如 SOH 低估 10%、SOC_pred 恰好以更快速率变化使 ΔSOC 也偏大），L_physics 不会报错。这构成一个**循环依赖**——两个预测量互相对答案，没有独立锚点。

#### 4.3.2 L_consistency 的锚定作用

L_consistency 提供了打破循环的锚点。V_measured 是真实传感器读数，OCV(·) 是单调函数：

```
L_consistency = Huber(V_measured, OCV(SOC_pred) + I·R0_est)
                    ↑                ↑
               物理真实值        仅依赖 SOC_pred
```

梯度传递链：

```
V_measured（真实）→ L_consistency → SOC_pred 被拉向真值
                                    ↓
                              SOC_pred 锚定后
                                    ↓
        L_physics 中 ΔSOC_pred ≈ 真 ΔSOC（因为 SOC 已锚定）
                                    ↓
                强制 SOH_pred 匹配真 SOH（否则 ΔSOC_phys 不对）
```

**结论**：L_consistency + L_physics 组合可以工作，但前提是 L_consistency 提供足够强的 SOC 锚定。两个脆弱场景：

- **放电/动态工况**：V_measured = OCV + V_p1 + V_p2 + I·R0，仅用 I·R0 近似极化电压，残差大 → SOC 锚定弱
- **OCV 老化偏移**：电池老化后 OCV-SOC 曲线偏移，OCV(SOC_pred) 系统性偏离 V_measured → 锚定方向有偏

#### 4.3.3 修正形式：直接用可测物理量作为桥梁

将依赖关系反转——用**直接测量的 ∫I·dt** 替代网络输出的 ΔSOC_phys，让 SOC 和 SOH 同时接受同一个测量量的监督：

```
原始（弱锚定）：
  L_physics = Huber( ΔSOC_pred , η·∫I·dt / (SOH_pred · C_nom) )
                        ↑                    ↑
                    网络输出             含网络输出（循环依赖）

修正（强锚定）：
  L_physics = Huber( ΔSOC_pred · SOH_pred · C_nom , η·∫I·dt )
                        ↑          ↑                    ↑
                    网络输出    网络输出             直接测量值
```

**为什么修正形式更稳健**：

- `η·∫I·dt` 是电流传感器的直接积分值，**不依赖任何网络输出**——这是独立于网络的物理真值
- `ΔSOC_pred · SOH_pred · C_nom` 是网络对"这段时间可用容量变化"的预测
- 两者的差值同时产生流向 SOC 和 SOH 的梯度：

```
∂L_physics/∂SOC_pred  = Huber' · SOH_pred · C_nom · sign(ΔSOC)
∂L_physics/∂SOH_pred  = Huber' · ΔSOC_pred · C_nom
```

**修正后的梯度链**（相比原始形式的关键差异）：

```
原始：L_physics 的梯度只要求 SOC_pred 和 SOH_pred 互相自洽
      → 两者可联动漂移，唯 L_consistency 提供锚定

修正：L_physics 的梯度直接要求 SOC_pred · SOH_pred ≈ 测量值
      → ∫I·dt 是独立锚点，SOC 和 SOH 同时受约束
      → 结合 L_consistency（锚定 SOC），SOH 被双重约束
```

**数值示例**——假设真值 SOC=70%, SOH=90%, C_nom=180Ah，充电 ∫I·dt=18Ah（对应 ΔSOC=10%）：

```
若网络预测 SOC_pred=70%（锚定正确）, SOH_pred=80%（低估 10%）：
  ΔSOC_pred · SOH_pred · C_nom = 0.10 · 0.80 · 180 = 14.4 Ah
  η·∫I·dt = 18 Ah
  → 残差 3.6 Ah → 梯度推动 SOH_pred ↑（向 90% 修正）

若网络预测 SOC_pred=75%（偏高）, SOH_pred=90%（正确）：
  ΔSOC_pred · SOH_pred · C_nom = 0.15 · 0.90 · 180 = 24.3 Ah
  η·∫I·dt = 18 Ah
  → 残差 6.3 Ah → 梯度推动 SOC_pred ↓（向 70% 修正）
  → 同时 L_consistency 也在推 SOC_pred ↓（OCV(75%) ≠ V_measured）
  → 双重约束，修正更快
```

#### 4.3.4 适用范围与局限性

```
✅ 充电窗口：∫I·dt 大，信噪比高，L_physics 发挥主要作用
   → SOH 修正的主要驱动力

⚠️ 放电窗口：L_physics 不生效（训练时 mask 掉）
   → SOC 仅靠 L_consistency + L_task 约束
   → 放电时缺乏独立物理锚点（V_measured 含极化电压，OCV 近似不准）

⚠️ OCV 老化偏移：若 OCV 曲线因老化偏移，L_consistency 的锚定方向有偏
   → SOC_pred 被拉偏 → L_physics 中 ΔSOC_pred 也偏 → SOH 连带偏
   → 详见 §4.4（OCV 老化偏移的完整处理策略：定期重标定 + 在线漂移检测 + 自适应 λ2 衰减 + 跨支路校验）
```

### 4.4 电压一致性损失 L_consistency 与 OCV 老化偏移

#### 4.4.1 L_consistency 的基本形式

```
利用 OCV-SOC 曲线作为物理先验：

  V_pred_from_SOC = OCV(SOC_pred) + I·R0_est

  L_consistency = Huber(V_measured, V_pred_from_SOC)

其中 OCV(·) 是离线标定的查表函数（可微，通过线性插值实现）
R0_est 用 BMS 数据粗估或设为可学习标量
```

#### 4.4.2 OCV 老化偏移的影响范围

OCV-SOC 曲线并非终身不变。电池老化（SEI 膜增厚、正极材料损耗、可用锂损失）会导致 OCV 曲线发生系统性偏移。这个偏移**同时影响两个环节**：

```
① L_consistency（训练时）：
   离线标定的 OCV 曲线已偏移 → OCV(SOC_pred) ≠ 当前电池的真实 OCV
   → 即使 SOC_pred 完全正确，V_pred 也会偏离 V_measured
   → L_consistency 反向推动 SOC_pred 偏离真值
   → 连锁污染：SOC_pred 偏 → L_physics 中 ΔSOC_pred 偏 → SOH_pred 偏

② SOC 标签构造（§6.1.1）：
   SOC_anchor = OCV⁻¹(V_rest)  ← 用的也是同一套离线 OCV 曲线
   → 静置锚点本身就有偏
   → 安时积分填充后，整段 SOC 标签系统性偏移
   → 监督信号本身被污染
```

**量级估计**：

```
LFP 电池（混动机车主流选择）：
  · 中间平台区（SOC 30~80%）：OCV 曲线极平坦，dOCV/dSOC ≈ 1~3 mV/%
  · 老化导致的 OCV 偏移：10~30mV（1000 次循环后）
  → SOC 误差放大：30mV ÷ 2mV/% = 15% SOC 偏差（极端情况）
  → 但实际中 LFP 的平台区 OCV 对老化相对不敏感，偏移主要在两端

三元电池（NMC/NCA）：
  · OCV 斜率较陡，dOCV/dSOC ≈ 5~15 mV/%
  · 同量级 OCV 偏移 → SOC 偏差 2~6%，影响较小
```

#### 4.4.3 纯在线自校准策略

不做受控重标定，利用机车运行中自然出现的静置段，持续收集 (SOC_ref, V_rest) 样本对，在线拟合 OCV 曲线的老化偏移量 δ(SOC)。分层递进：

---

**第一层：冷启动 — 原始 OCV 撑过初期**

```
条件：累积合格样本对 < 20 组（新车或刚部署，静置段数据不足）

做法：
  · 使用电池厂原始 OCV 曲线（离线标定值）
  · λ2 按指数衰减（半衰期 ≈ 1 年），逐步降低对可能已老化的 OCV 的依赖
  · 同时启用 BMS SOC 弱锚定：
      L_BMS_anchor = Huber(SOC_pred, SOC_BMS)，权重 λ_bms = 0.02
    （BMS SOC 绝对精度不高但相对趋势可信，防止 SOC 在 OCV 锚定减弱时严重漂移）
  · 每出现一个合格静置段 → 收集一组 (SOC_ref, V_rest)，为第二层做准备

合格样本标准：
  · 静置时长 > 2h（|I| < 0.5A），确保电压充分松弛
  · 距最近 OCV 锚点 < 2h（SOC_ref 短期漂移远小于 OCV 老化偏移）
    SOC_ref 来自安时积分，不使用网络 SOC_pred（避免循环论证）
```

---

**第二层：δ(SOC) 在线拟合 — 核心自校准**

```
条件：累积 ≥ 20 组合格样本对

做法：
  Step 1 — 计算每组的 OCV 偏差：
    ΔV_i = V_rest_i - OCV_original(SOC_ref_i)

  Step 2 — 3 阶多项式拟合：
    δ(SOC) = a₀ + a₁·SOC + a₂·SOC² + a₃·SOC³
    → 仅 4 个参数，20 组样本足够稳定，不会过拟合
    → 用加权最小二乘，样本权重 ∝ SOC 标签质量分级的倒数
      （A 级样本权重 1.0，B 级 0.7，C 级 0.3）

  Step 3 — 修正 OCV：
    OCV_corrected(SOC) = OCV_original(SOC) + δ(SOC)

  Step 4 — 恢复 L_consistency 权重：
    λ2 恢复到初始满权重（OCV 被"刷新"了）
    下次衰减从此刻重新计时

为什么 3 阶多项式而非 MLP：
  · 样本量小（20~100 组），低参数量防止过拟合
  · 电池老化 OCV 偏移是平滑、缓慢的，多项式完全能刻画
  · 可解释：a₀ 是整体电压偏移，a₁ 是斜率变化（内阻增大），高阶项是曲率变化
```

---

**第三层：持续迭代 — 良性循环**

```
每新增 10 组合格样本 → 重拟合 δ(SOC)：

  更新后的 δ → OCV 更接近真实老化曲线
            → SOC 锚点更准（OCV⁻¹ 映射精度提升）
            → 安时积分起点更准 → SOC_ref 更准
            → 下一轮 δ 拟合质量更高
            → 良性循环

λ2 管理：
  · 每次拟合后 λ2 恢复满权重
  · 两次拟合之间 λ2 缓慢衰减（半衰期 ≈ 3 个月，比冷启动快，
    因为 OCV 仍在持续老化）
```

---

**第四层：8 支路冗余 — 中位数抗噪**

```
每次静置，8 条支路各自产生一组 (SOC_ref_i, V_rest_i) → 一次获得 8 组样本

拟合时取 8 条支路 ΔV 的中位数作为拟合目标：
  ΔV_target(SOC) = median(ΔV_1, ΔV_2, ..., ΔV_8) 在同一 SOC 点

收益：
  · 单支路传感器异常不会污染 δ（中位数自动滤除离群值）
  · 全部 8 条 ΔV 同步偏移 → 确认是 OCV 整体老化而非支路级异常
  · 样本积累速度快 8 倍 → 更快进入第二层
```

---

**第五层：退化兜底**

```
以下情况触发保护性回退：

① δ(SOC) 超出物理合理范围：
   若任意 SOC ∈ [0,1] 处 |δ(SOC)| > 50mV：
     → 回退到上一版 δ，标记异常，继续收集样本但不更新
     → 可能原因：传感器系统性故障、电池异常损坏、样本污染

② 样本质量不均：
   若 SOC_ref 来自 C 级标签（距锚点 > 2h）：
     → 该样本仅参与中位数计算（抗噪），不主导拟合方向（权重 ×0.3）

③ 长期无静置段：
   若连续 60 天无合格静置段（机车长期连续运行不停机）：
     → λ2 衰减到 0，仅靠 L_task + BMS 弱锚定维持
     → 一旦恢复静置，优先收集样本重建 δ（冷启动流程，但有历史样本积累）
```

#### 4.4.4 跨支路 OCV 一致性校验

利用 8 支路并联架构（§3）的自然冗余——同化学体系的 8 条支路，OCV 老化趋势应高度一致。校验同时服务于两个目的：检测支路级异常 + 确认 OCV 整体老化。

```
每 100ms 随推理自然输出：

  同一静置时刻，8 条支路的 (V_rest_i, SOC_pred_i) 应落在同一条 OCV 曲线上。

  情况 1 — 单支路异常（传感器故障或异常老化）：
    ΔV_i = |V_rest_i - OCV(SOC_pred_i)|
    median_ΔV = median(ΔV_1...ΔV_8)
    
    若 ΔV_k - median_ΔV > 20mV 且持续 > 10 分钟：
      → 支路 k 的传感器或电芯有问题，不是 OCV 曲线问题
      → 触发支路级警告，δ 拟合时该支路被中位数自动滤除（§4.4.3 第四层）
      
  情况 2 — 整体 OCV 老化（所有支路同步偏移）：
    若 median_ΔV > 15mV 且持续跨越多段静置：
      → 确认 OCV 曲线整体老化
      → 若当前处于冷启动层：加速 λ2 衰减（速率 ×2）
      → 若处于持续迭代层：触发一次提前重拟合（不等满 10 组）
```

### 4.5 单调性损失 L_monotonicity

```
SOH 不应回升：
  L_monotonicity = max(0, SOH_pred(i+1) - SOH_pred(i) + margin)

  仅对同一支路的相邻两次 SOH 输出计算
  margin=0.005（容忍 0.5% 的估算波动）
```

## 5. 训练方案

### 5.1 训练标签体系

DNN-MTL 是一个监督学习框架，需要 SOC / SOH 两类逐帧标签。但实车上没有 SOC/SOH 真值传感器，因此需要一套从可获取的物理量中间接构造标签的方法。

---

#### 5.1.1 SOC 标签：安时积分 + OCV 锚点标定

**原理**：在没有 SOC 传感器的条件下，电池领域公认的"伪真值"构造方法是：利用长静置后的端电压等于 OCV 这一物理事实获取 SOC 绝对锚点，锚点之间用安时积分填充。

**可用字段**：
- `uiBMS3SumVolt`（支路总电压，静置时 ≈ OCV）
- `uiBMS3SumCurr`（支路总电流，含充放电方向）
- `CCU2IDU_地面充电工况` / `CCU2IDU_混动工况`（辅助判断静置段）

**离线处理流程**（每条支路独立执行）：

```
Step 1: 静置段检测
  条件：|I| < I_threshold（如 0.5A）持续 > 1 小时
  输出：静置段的起止时间 [t_start, t_end] 和稳定端电压 V_rest

Step 2: OCV → SOC 锚点映射
  SOC_anchor = OCV⁻¹(V_rest, T_ambient)
  查离线标定的 OCV-SOC 曲线（来自电池厂或同型号电芯实验室测试，含温度补偿）

Step 3: 安时积分填充（锚点之间）
  SOC(t) = SOC_anchor + η · ∫_{t_anchor}^{t} I(τ) dτ / C_nom
  其中：
    η   = 库仑效率（充电取 η_chg，放电取 1.0）
    C_nom = 支路额定容量（已知设计参数，如 180Ah）

Step 4: 锚点间漂移修正
  若在两个锚点之间出现累积漂移：
    drift = SOC_anchor2 - SOC_coulomb(t_anchor2)
  按时间线性分配修正量到中间的每个采样点：
    SOC_corrected(t) = SOC_coulomb(t) + drift · (t - t_anchor1) / (t_anchor2 - t_anchor1)
```

**标签质量分级**（决定训练时的损失权重）：

| 等级 | 条件 | 预期误差 | 训练权重 |
|:----:|------|:-------:|:-------:|
| A 级 | 距离最近锚点 < 30min，且两锚点间漂移 < 2% | ±1~2% | 1.0 |
| B 级 | 距离最近锚点 30min~2h，或漂移 2~5% | ±3~5% | 0.7 |
| C 级 | 距离最近锚点 > 2h，或漂移 > 5%，或长期连续运行无锚点 | ±5~10% | 0.3 |

**注意**：若机车长期连续运行不停机（无静置锚点），SOC 标签漂移会累积。这是物理极限，不是方法缺陷——BMS 自身的 SOC 在同样条件下也会漂移。C 级标签提供弱监督信号，配合物理损失（L_consistency 中 V_measured 始终是真实物理量）可部分约束漂移。

---

#### 5.1.2 SOH 标签：充电片段容量反推

**原理**：SOH = 当前可用容量 / 额定容量。在完整充电片段中，通过首尾 SOC 差值和累计充入电量反推当前容量。

**可用字段**：
- `uiBMS3SumCurr`（充电电流积分 → 充入电量）
- `uiBMS3SumVolt`（充电前后的静置端电压 → OCV → SOC 首尾值）
- `udBMS3AccumChrgCapacity`（BMS 累计充电量，辅助校验）
- `CCU2IDU_地面充电工况`（确认充电片段）
- `CCU2IDU_机车里程`（退化趋势的里程维度）

**离线处理流程**：

```
Step 1: 有效充电片段筛选
  必要条件（全部满足）：
    · CCU2IDU_地面充电工况 = 1（确认是地面充电）
    · 片段首尾各有一个有效静置锚点（|I| < 0.5A 持续 > 1h）
    · ΔSOC = SOC_end - SOC_start > 30%（足够大的 SOC 跨度保证容量估计精度）
  可选条件：
    · 充电过程中无故障标志位触发（保证数据质量）

Step 2: 容量反推
  SOC_start = OCV⁻¹(V_rest_before_charge)
  SOC_end   = OCV⁻¹(V_rest_after_charge)
  ΔSOC      = SOC_end - SOC_start
  C_current = ∫I_charge(t) dt / ΔSOC
  SOH       = C_current / C_nom

Step 3: 片段内逐帧赋值
  该充电片段内的所有采样点共享同一个 SOH_label：
    SOH_label(t) = SOH，∀ t ∈ [t_charge_start, t_charge_end]
  
  物理依据：单个充电片段持续数十分钟到数小时，SOH（容量衰减）在此时长内几乎不变。
```

**标签稀疏性处理**：

```
预期频率：每周 1~3 个有效充电片段 → 每年 50~150 个 SOH 标签
处理策略：
  · 片段内所有帧共享 SOH_label（增加有效训练样本数）
  · L_monotonicity（单调性损失）在没有新 SOH 标签的时段提供弱约束
  · SOH 头在训练时仅对充电窗口计算损失，放电窗口不参与 L_SOH
  · SOH 标签在任务损失中的权重 β=0.5（低于 SOC 的 α=1.0，因为稀疏 + 噪声大）
```

---

#### 5.1.3 标签汇总

| 标签 | 构造方法 | 频率 | 标签质量 | 训练策略 |
|------|------|:--:|:--:|------|
| **SOC_label** | OCV 锚点 + 安时积分 + 漂移修正 | 逐帧（10Hz） | A/B/C 三级（±1~10%） | A/B 级全权重，C 级 ×0.3；配合 L_consistency 约束 |
| **SOH_label** | 充电片段容量反推，片段内共享 | 每充电片段 1 个（~50-150/年） | 中等（依赖首尾 OCV 锚点精度） | 仅在充电窗口参与 L_SOH，权重由 σ_soh 自动调节 |

### 5.2 分阶段训练方案

双分支 + 层级特定约束需要分阶段训练，防止两个时间尺度不同的任务互相干扰：

```
阶段 1 — SOC 预训练（60 epochs, lr=1e-3, AdamW）：
  冻结：SOH 分支 + Star FC
  训练：共享编码器（TCN + 上下文 + 投影）+ SOC 分支 + log_sigma_soc
       （注意：SOC 分支从 Z 取特征，交叉注意力不在 SOC 路径上，可选择性冻结）
  损失：L = L_SOC/(2·σ_soc²) + log(σ_soc) + 0.05·L_consistency

阶段 2 — SOH 预训练（60 epochs, lr=5e-4, AdamW）：
  冻结：SOC 分支 + Star FC
  训练：交叉注意力 + SOH 分支（lr=5e-4）+ log_sigma_soh
        + 共享编码器（lr=1e-4，仅微调）
  损失：L = L_SOH/(2·σ_soh²) + log(σ_soh) + 0.1·L_physics + 0.01·L_mono（仅充电窗口）

阶段 3 — 联合微调（40 epochs, lr=1e-4, AdamW）：
  解冻：全部参数（含 Star FC + log_sigma_soc + log_sigma_soh）
  损失：L_total = L_task_weighted + 0.1·L_physics + 0.05·L_consistency + 0.01·L_mono
  关键：不确定性参数自适应调节 SOC/SOH 权重，Star FC 学习乘积耦合

阶段 4 — MC Dropout 校准（20 epochs, lr=1e-5）：
  固定：全部参数
  仅微调：Dropout 相关统计量
```

阶段 4 — MC Dropout 校准（20 epochs, lr=1e-5）：
  固定：共享编码器 + SOC/SOH 分支 + Star FC
  仅微调：Dropout 相关的 BatchNorm 统计量
  目的：使预测方差与真实误差的相关系数最大化
```

**设计要点**：

- SOC 分支从浅层 Z 取特征，阶段 1 不涉及交叉注意力——这是有意设计：先让 SOC 在纯时序+上下文特征上学稳，再引入支路间对比（阶段 2）。
- 阶段 2 冻结 SOC 分支但不冻结交叉注意力——SOH 分支能从交叉注意力首次受益，学会利用支路间退化对比。
- 阶段 3 不确定性参数 + Star FC 同时生效：σ 自适应调节权重，Star 编码乘积耦合，层级特征提供信息互补。
- 与 V1.2 的关键差异：V1.2 两个分支都从 Z' 出发；V1.3 SOC 从 Z、SOH 从 Z'，各自匹配任务的时间尺度特性。

### 5.3 训练配置

```
优化器：AdamW, weight_decay=1e-5
批次大小：64（每个样本包含同一时刻 8 条支路数据，等效 512 个单支路样本）
总参数量：~1.22M（8 支路架构含交叉注意力 + Star FC，详见 §3.12）
SOC/SOH 标签：弱标签（±2~3%）
MC Dropout 采样次数 T=20
```

### 7.2 跨机车泛化与部署策略

同一套网络可以部署到多台同型号机车，**不需要每台车单独训练**。关键区分：

| 组件 | 学到的是什么 | 跨车通用？ | 部署到新车时的处理 |
|------|------------|:--:|------|
| 共享编码器 (TCN + 上下文 + 投影 + 交叉注意力) | 电池物理规律（电压响应模式、OCV 形状、充放电行为） | ✅ 是 | 直接复用，不重新训练 |
| SOC / SOH 分支 | SOC→电压 和 SOH→容量衰减的映射关系 | ✅ 是 | 直接复用 |
| 支路嵌入 `E ∈ R^{8×32}` | 每条支路的个体身份（传感器偏置、老化速率、负载分配） | ❌ 否 | 重新随机初始化 8 行，微调 |

**部署到新车的流程**：

```
方案 A（推荐，有少量新车数据）：
  1. 将训练好的模型部署到新车 CCU
  2. 将 E 矩阵全部重新随机初始化（8×32 个参数，仅 256 个 float32）
  3. 冻结共享编码器和 SOC/SOH 分支
  4. 用新车前几次充电的数据微调嵌入（~30 epochs，数据量 ≈ 几小时运行数据）
  5. 微调完成后解除冻结，正常推理
  
  → 理由：编码器学到的物理规律对同型号电池通用，
    只有支路个体差异需要重新学习

方案 B（零数据冷启动）：
  1. 直接部署，所有参数不变
  2. 嵌入使用训练时的值（假设同型号机车支路位置特征近似）
  3. 前几次充电的 SOH 估计精度偏低（因为嵌入未反映新车的真实老化状态）
  4. 积累 2~3 次深度充电后，后台运行方案A的微调流程
  5. 微调完成后在线替换嵌入矩阵（无需重启推理）

方案 C（换电芯，单支路重置）：
  1. 仅将被换支路对应的嵌入行重新随机初始化
  2. 冻结所有其他参数
  3. 用该支路后续数据微调该行嵌入（仅 32 个参数）
  4. 其余 7 条支路不受影响，持续正常工作
```

**只有以下情况才需要完整重新训练**：
- 换用不同型号/化学体系的电池（如 LFP→NMC），物理规律完全改变
- 支路拓扑变化（如 8 支路→6 支路），网络输入维度不兼容

## 8. 方案对比总结

| 维度 | AEF-GPR | DNN-MTL |
|------|---------|---------|
| **核心创新** | 增广EKF硬约束 + GPR不确定性闭环 | 多任务共享编码 + 物理损失软约束 |
| **SOC 频率** | 10Hz | 10Hz |
| **SOH 频率** | 每充电片段 | 充电时更新 |
| **物理约束** | 硬约束（方程驱动） | 软约束（损失驱动） |
| **训练** | 模块独立，数据需求小 | 端到端统一，数据需求大 |
| **可解释性** | 每个状态对应物理量 | 黑盒特征 |
| **不确定性** | GPR 后验方差（天然） | MC Dropout（近似） |
| **车端部署** | ~162KB，不需要推理框架 | ~120KB，需要 ONNX/TensorRT |
| **适用场景** | 数据少、需要可解释性 | 数据多、追求 SOTA 精度 |
| **论文策略** | 主方案（创新性强） | Baseline 或对比方案 |
