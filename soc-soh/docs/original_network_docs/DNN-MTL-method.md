# DNN-MTL：物理感知深度多任务联合估计网络

> 面向马钢混动机车 8 支路并联电池组的 SOC / SOH 联合估计（纯深度学习方案）
> V1.3：层级特定约束 + Star Operation 结构耦合 + 不确定性自适应加权

---

## 1. 问题

**输入**：每 100ms（10Hz），8 条并联支路各自上报 6 通道时序——总电压、最高/最低单体电压、总电流、最高/最低温度，以及 5 个上下文标量（SOH 锚点、工况标记、里程、BMS 自带 SOC、环境温度）。

**输出**：每 100ms，8 条支路各自的 SOC、SOH（仅充电时更新）、置信区间，以及 Pack 级聚合值。

**约束**：仅使用车地协议现有字段，总参数量 ~1.22M，剪枝量化后 ~122KB，可部署于 CCU。

---

## 2. 总体架构

```
CAN 数据 (每100ms)
  │
  ├─→ 数据预处理 (字段校验 / 滑动窗口 W=128 / 缺失填充 / Z-score 归一化 / 工况识别)
  │
  ├─→ [第1路] 时序输入 [8,128,6]  ──→ 共享 TCN (4层) ──→ [8,128]
  │
  ├─→ [第2路] 上下文输入 [8,5]    ──→ 共享 MLP ──→ [8,64]
  │
  ├─→ 支路嵌入 E ∈ R^{8×32} (可学习，编码支路位置角色)
  │
  └─→ 拼接: [128|64|32] = [224] ──→ FC(224→256) ──→ 共享特征 Z [8,256]
                                        │
                    ┌───────────────────┴───────────────────┐
                    ↓ (浅层出口)                             ↓ (深层出口)
              ┌─────────────┐                    ┌─────────────────────┐
              │  SOC 分支    │                    │  交叉支路自注意力     │
              │ 从 Z 取特征  │                    │  (8条支路互相看)      │
              │             │                    └──────────┬──────────┘
              │ FC(256→128) │                               ↓
              │ + GELU      │                          Z' [8,256]
              │ → F_soc[128]│                               │
              └──────┬──────┘                    ┌──────────┴──────────┐
                     │                           │  SOH 分支           │
                     │                           │  从 Z' 取特征       │
                     │                           │  FC(256→128)       │
                     │                           │  + GELU            │
                     │                           │  → F_soh [128]     │
                     │                           └──────────┬─────────┘
                     │                                      │
                     │     ┌────────────────────────────────┘
                     │     │
                     ↓     ↓
              ┌──────────────────────┐
              │  Star Operation      │  ← 结构级物理乘积耦合
              │  F_star = F_soc ⊙ F_soh
              │  FC(128→128) + GELU  │
              └──────────┬───────────┘
                         │
              F_soc' = F_soc + F_star
              F_soh' = F_soh + F_star
                         │
              ┌──────────┴──────────┐
              ↓                     ↓
        FC(128→64)+GELU       FC(128→64)+GELU
        FC(64→1)+Sigmoid      FC(64→1)+Sigmoid
        → SOC [8,1]           → SOH [8,1]
        10Hz 全工况            仅充电时更新
              │                     │
              └──────────┬──────────┘
                         ↓
                 MC Dropout (T=20)
                 → SOC±σ, SOH±σ
                         ↓
                    Pack 聚合
```

**关键设计决策**：

> **层级特定约束**：SOC 是快变量（秒级充放电波动），从交叉注意力之前的浅层特征 Z 取输入，保留对局部时序模式的敏感度。SOH 是慢变量（月/年级容量衰减），从交叉注意力之后的深层特征 Z' 取输入——Z' 经过了 8 条支路互相对比，捕捉到的全局退化模式远比单支路波形丰富。两个分支在 128 维处通过 Star Operation 汇合，乘积耦合编码物理交互。
>
> **不确定性自适应加权**：训练损失中用两个可学习参数 σ_soc、σ_soh 自动平衡 SOC 和 SOH 的权重，替代手动设置的 α=1.0, β=0.5。SOH 标注稀疏、噪声大 → σ_soh 自动增大 → SOH 损失权重自动降低，无需人工调参。

### 2.1 数据预处理

每支路维护一个 W=128（~2 分钟）的环形缓冲区。新帧到达时做字段合法性校验，缺失帧前向填充或线性插值，传感器尖峰用中位数替换。随后各通道独立做 Z-score 归一化，识别当前工况（充电/放电/静置），维护 SOH 锚点的指数移动平均。

### 2.2 共享时序编码器 (TCN)

8 条支路的 [128,6] 序列作为 batch=8 并行通过同一套 TCN 权重。TCN 含 4 层空洞因果卷积（膨胀率 [1,2,4,8]，kernel=5，每层 64 通道），层间 BatchNorm + GELU + 残差连接。最后全局平均池化压缩时间维度，经 FC(64→128) 得到每条支路的 128 维时序特征。

### 2.3 上下文编码器

5 个标量（SOH_anchor、mode、mileage、SOC_BMS、T_ambient）经 FC(5→32→64) + LayerNorm + GELU 映射为 64 维上下文向量。

### 2.4 支路嵌入与特征融合

可学习嵌入矩阵 `E ∈ R^{8×32}` 编码支路位置角色的物理共性。TCN 特征 [128]、上下文特征 [64]、支路嵌入 [32] 拼接为 [224]，经共享投影层 FC(224→256) 融合为统一表示 Z ∈ [8,256]。

### 2.5 层级特定约束：浅层出口 vs 深层出口

两个分支从编码器**不同深度**取特征——遵循"快慢变量"分配原则：

| 特征出口 | 来源 | 语义层次 | 给谁 | 理由 |
|---------|------|---------|:--:|------|
| **浅层 Z** | 交叉注意力之前 | TCN+上下文+嵌入融合，保留局部时序细节 | SOC 分支 | SOC 是快变量，需要感知秒级充放电波动 |
| **深层 Z'** | 交叉注意力之后 | 8 条支路互相对比后的全局特征 | SOH 分支 | SOH 是慢变量，支路间对比捕捉的退化模式远丰富于单支路波形 |

### 2.6 Star Operation 结构乘积耦合

两个分支在各自的 128 维中间特征处汇合，通过 Star Operation 实现物理乘积耦合：

```
F_soc [128] ← SOC分支第一层FC输出
F_soh [128] ← SOH分支第一层FC输出

F_star = (F_soc ⊙ F_soh) → FC(128→128) + GELU
F_soc' = F_soc + F_star    （残差注入）
F_soh' = F_soh + F_star
```

物理直觉：`ΔSOC · SOH · C_nom = 可用容量变化` 是乘积耦合。Star Operation 在网络结构层面内置了这种交互，与损失函数的 L_physics 形成双层约束。

不确定性通过 MC Dropout 获得——推理时 T=20 次前向，取标准差为 ±σ。

## 3. 物理约束损失函数 + 不确定性自适应加权

### 3.1 任务损失

```
L_SOC = Huber(SOC_pred, SOC_label)
L_SOH = Huber(SOH_pred, SOH_label)    ← 仅充电窗口计算
```

### 3.2 不确定性自适应加权

两个可学习参数 `log_sigma_soc`、`log_sigma_soh`（初始化为 0，即 σ=1）自动平衡任务权重：

```
σ_soc = exp(log_sigma_soc)
σ_soh = exp(log_sigma_soh)

L_task_weighted = L_SOC / (2·σ_soc²) + L_SOH / (2·σ_soh²) + log(σ_soc) + log(σ_soh)
```

**工作原理**：SOH 标注稀疏、噪声大 → L_SOH 原始值偏高 → 梯度推动 σ_soh 增大 → 1/(2σ²) 自动降低 → SOH 权重自动减小。两个 `log(σ)` 正则项防止 σ 无限增长。全程无需手动调整 α/β。

### 3.3 物理耦合与正则损失

```
L_physics     = Huber(ΔSOC_pred · SOH_pred · C_nom,  η·∫I·dt)   ← 仅充电窗口
L_consistency = Huber(V_measured, OCV(SOC_pred) + I·R₀)
L_mono        = max(0, SOH(t+1) − SOH(t) + 0.005)
```

### 3.4 总损失

```
L_total = L_task_weighted + 0.1·L_physics + 0.05·L_consistency + 0.01·L_monotonicity
```

其中 `L_task_weighted` 的权重由 σ_soc、σ_soh 自动调节；L_physics/L_consistency/L_mono 保持固定权重（它们是物理先验，不应被数据驱动的不确定性缩放）。

## 4. 分阶段训练方案

```
阶段 1 — SOC 预训练（60 epochs, lr=1e-3, AdamW）：
  冻结：SOH 分支 + Star FC
  训练：共享编码器 + SOC 分支 + log_sigma_soc
  损失：L = L_SOC/(2·σ_soc²) + log(σ_soc) + 0.05·L_consistency

阶段 2 — SOH 预训练（60 epochs, lr=5e-4, AdamW）：
  冻结：SOC 分支 + Star FC
  训练：共享编码器（lr=1e-4）+ SOH 分支（lr=5e-4）+ log_sigma_soh
  损失：L = L_SOH/(2·σ_soh²) + log(σ_soh) + 0.1·L_physics + 0.01·L_mono（仅充电窗口）

阶段 3 — 联合微调（40 epochs, lr=1e-4, AdamW）：
  解冻：全部参数（含 Star FC + log_sigma_soc + log_sigma_soh）
  损失：L_total = L_task_weighted + 0.1·L_physics + 0.05·L_consistency + 0.01·L_mono
  关键：不确定性参数 + Star FC 同时生效，结构耦合与自适应权重互补

阶段 4 — MC Dropout 校准（20 epochs, lr=1e-5）：
  固定：全部参数
  仅微调：Dropout 相关统计量
```

**设计要点**：阶段 1 只训练 SOC，σ_soc 快速收敛到合理值；阶段 2 引入 SOH，σ_soh 从初始 σ=1 开始自适应；阶段 3 两个 σ 在完整损失下联合优化，Star FC 同时学习乘积耦合。

---

## 5. 关键设计决策

| 决策                        | 理由                             |
| ------------------------- | ------------------------------ |
| 滑动窗口 W=128，全工况覆盖          | 10Hz 实时输出，不区分充放电               |
| SOH 仅充电时更新                | SOH 是慢变量，放电时信息不足               |
| TCN 而非 LSTM               | 可并行推理、感受野可控、嵌入式友好              |
| 8 支路共享编码器 + 交叉注意力         | 1.22M 参数 vs 8 独立模型 9.6M           |
| 支路嵌入编码位置角色              | 跨包通用，部署零成本复用                    |
| **层级特定约束**（Z→SOC, Z'→SOH） | 快慢变量分深度取特征，比同层双头更符合物理直觉       |
| **Star Operation 结构乘积耦合**  | 逐元素乘内置物理乘积，与 L_physics 互补       |
| **不确定性自适应加权**（σ_soc/σ_soh）| 替代手动 α/β，自动适应 SOH 稀疏标注          |
| **分阶段训练（冻结→解冻）**         | 先学 SOC 稳基座，再学 SOH，最后联合微调       |
