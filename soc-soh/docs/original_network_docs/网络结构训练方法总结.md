## 1. Advancing Real-World Image Dehazing: Perspective, Modules, and Training

**发表**：IEEE TPAMI 2024 | IF 20.8 | 作者：Yuxin Feng, Long Ma, Xiaozhe Meng, Fan Zhou, Risheng Liu, Zhuo Su

### 1.1 动机

真实世界图像去雾面临一个本质矛盾：去雾需要网络对高频噪声（雾气颗粒、伪影）高度敏感，而色彩重建需要网络聚焦于低频色度与结构信息（天空、建筑本色）。单头网络在两者间被迫折中，产生模糊伪影——这就是"误差积累"（Error Accumulation）与"任务平衡崩溃"（Task Balancing Collapse）。

### 1.2 网络结构（CANS架构）

```
输入有雾图像
    │
    ▼
┌─────────────────┐
│   共享骨干网     │  ← 提取泛化视觉特征（如ResNet/U-Net类编码器）
│   (Backbone)    │
└───────┬─────────┘
        │ 共享特征 F
        ▼
┌───────────────────────────────────────┐
│       双头交互模块                      │
│  (Dual-head Interaction Module)       │
│                                       │
│   ┌──────────┐    ┌──────────┐        │
│   │ 去噪头    │◄──►│ 重建头    │        │
│   │ Denoising │ 交叉 │ Reconst. │        │
│   │  Head     │ 注意力│  Head    │        │
│   └─────┬─────┘    └─────┬─────┘       │
│         │                │             │
│   去噪特征图         重建特征图          │
└─────────┼────────────────┼─────────────┘
          ▼                ▼
     去雾干净图像      色彩校正图
          │                │
          └───────┬────────┘
                  ▼
            最终去雾输出
```

**核心设计要点**：

- **共享骨干网**：统一提取泛化特征，减少参数冗余。去噪和重建共享底层特征，避免重复计算。
- **去噪头（Denoising Head）**：参数精简的特定任务分支，对高频噪声响应敏感，专门负责消除雾气颗粒和伪影。
- **色彩重建头（Reconstruction Head）**：聚焦低频色度与结构信息，负责恢复场景的真实色彩和光照。
- **双头交互模块**：核心创新——不是两个头各自独立输出。通过交叉注意力（Cross Attention）让两个头相互"看见"对方学到的特征：
  - 共享参数矩阵 $W_K$、$W_V$ → 生成公共的 Key $K$ 和 Value $V$ 特征
  - 去噪头用自身参数 $W_Q^{den}$ 生成查询 $Q_{den}$
  - 重建头用自身参数 $W_Q^{rec}$ 生成查询 $Q_{rec}$
  - $\text{Attention}(Q_{den}, K, V)$ 和 $\text{Attention}(Q_{rec}, K, V)$ 分别计算
  - 这种非对称设计确保：**在维持各自任务特征空间独立性的前提下，动态对齐任务优先级**

### 1.3 训练策略

- **端到端联合训练**：骨干网 + 双头 + 交互模块同时优化，不做分阶段训练
- 每轮迭代同时计算去噪损失和重建损失
- 两个头的梯度通过交叉注意力模块相互影响，形成隐式的任务平衡

### 1.4 损失函数

联合损失函数：

$$L_{total} = \lambda_{den} \cdot L_{denoising} + \lambda_{rec} \cdot L_{reconstruction}$$

- $L_{denoising}$：去噪损失，通常是 L1/L2 + 感知损失（VGG特征差异），确保去雾后清晰度
- $L_{reconstruction}$：色彩重建损失，包括颜色恒常性约束和结构保持损失
- 交叉注意力机制替代了传统的手动权重调节——网络在训练中自适应学习两个任务的相对重要性

## 2. Dual Compensation Residual Networks for Class Imbalanced Learning

**发表**：IEEE TPAMI 2024 | IF 20.8

### 2.1 动机

长尾数据分布（Long-tailed Data）中，少数"头部类别"占据大量样本，大量"尾部类别"样本极少。传统方案（重采样、重加权、边际调整）陷入"零和博弈"：
- 重平衡策略 → 尾部类别**过拟合**（测试特征漂移到头部类别特征云）
- 抑制重平衡 → 头部类别**欠拟合**（分类器学不到头部知识）

### 2.2 网络结构

```
输入图像
    │
    ▼
┌──────────┐
│  骨干网   │  ← 特征提取器（ResNet等）
│ Backbone │
└────┬─────┘
     │ 特征 f
     ▼
┌─────────────────────────────────────────────┐
│           双头补偿模块                         │
│                                             │
│  ┌──────────────────┐  ┌──────────────────┐ │
│  │ 特征补偿模块 FCM   │  │ Logit补偿模块 LCM  │ │
│  │                  │  │                  │ │
│  │ • 估计每个尾部类别 │  │ • 将漂移向量沿类内 │ │
│  │   的多模式特征漂移 │  │   变异方向平移扩展  │ │
│  │   方向            │  │ • 覆盖更大补偿空间  │ │
│  │ • 补偿漂移后的特征 │  │                  │ │
│  └────────┬─────────┘  └────────┬─────────┘ │
│           │                     │           │
│           └──────────┬──────────┘           │
│                      ▼                      │
│              补偿后的 Logits                  │
└──────────────────────┬───────────────────────┘
                       ▼
┌──────────────────────────────────────┐
│   残差平衡多代理分类器 RBMC            │
│                                      │
│   • 均匀学习残差路径                   │
│   • 多个分类器代理并行预测              │
│   • 残差连接保证头部类别不退化          │
└──────────────────┬───────────────────┘
                   ▼
              最终分类结果
```

**三个模块详解**：

| 模块 | 解决的问题 | 机制 |
|------|-----------|------|
| **FCM**（Feature Compensation Module） | 尾部类别过拟合 | 观察：尾部类别测试特征会向多个相似头部类别的"特征云"漂移。FCM为每个尾部类别估计多模式的漂移方向向量，并在特征空间中进行补偿，将漂移的特征"拉回"正确位置 |
| **LCM**（Logit Compensation Module） | 补偿覆盖不足 | FCM估计的漂移方向是确定的，但实际漂移有随机性。LCM将该方向沿类内变异方向平移扩展，扩大有效补偿空间，提高鲁棒性 |
| **RBMC**（Residual Balanced Multi-agent Classifier） | 头部类别欠拟合 | 重平衡策略会破坏分类器对头部类别的判别力。RBMC提供一条"均匀学习的残差路径"，多个代理分类器并行，残差连接确保头部知识不被稀释 |

### 2.3 训练策略

**两阶段精密补偿训练**：

1. **第一阶段（解决过拟合）**：FCM + LCM 联合训练
   - 对每个尾部类别，FCM学习特征漂移方向 → LCM扩展补偿范围
   - 两个模块的梯度在特征空间和Logit空间联合优化
2. **第二阶段（解决欠拟合）**：引入RBMC
   - RBMC的残差路径与主分类路径并行
   - 主路径负责尾部类别的补偿分类，残差路径维持头部类别的判别力
   - 两路径输出融合得到最终预测

### 2.4 损失函数

$$L_{total} = L_{cls} + \alpha \cdot L_{FCM} + \beta \cdot L_{LCM} + \gamma \cdot L_{RBMC}$$

- **$L_{cls}$**：标准交叉熵分类损失（对头部类别保持高权重）
- **$L_{FCM}$**：特征漂移补偿损失 → 最小化补偿后特征与真实类别中心的距离
- **$L_{LCM}$**：Logit空间补偿损失 → 最大化尾部类别Logit在扩展补偿空间中的置信度
- **$L_{RBMC}$**：残差平衡损失 → 确保多个代理分类器的预测一致性，同时鼓励各代理覆盖不同类别子集

## 3. Dual-head Genre-instance Transformer Network for Arbitrary Style Transfer

**发表**：ACM MM 2024 | 顶级会议 | 作者：Meichen Liu, Shuting He, Songnan Lin, Bihan Wen

### 3.1 动机

任意风格迁移（Arbitrary Style Transfer）需要同时捕获两种粒度的风格信息：
- **全局风格（Genre-level）**：整幅风格图的宏观艺术风格（如"油画"、"水墨"、"浮世绘"）
- **实例细节（Instance-level）**：笔触纹理、色彩渐变、局部图案等细粒度特征

单头Transformer往往只能捕获单一粒度的风格表示，导致生成图像要么全局风格对但缺乏细节，要么细节丰富但整体风格跑偏。

### 3.2 网络结构

```
内容图像 I_c              风格图像 I_s
    │                         │
    ▼                         ▼
┌──────────┐           ┌──────────┐
│ 内容编码器│           │ 风格编码器│
│  (CNN)   │           │  (CNN)   │
└────┬─────┘           └────┬─────┘
     │ 内容特征 Fc           │ 风格特征 Fs
     │                       │
     │              ┌────────┴────────┐
     │              ▼                 ▼
     │    ┌──────────────┐  ┌──────────────┐
     │    │  风格头        │  │  实例头       │
     │    │ Genre Head    │  │ Instance Head │
     │    │              │  │              │
     │    │ • 全局风格    │  │ • 笔触纹理    │
     │    │   类别嵌入    │  │   细节嵌入    │
     │    │ • 跨图注意力  │  │ • 局部自注意力│
     │    └──────┬───────┘  └──────┬───────┘
     │           │                 │
     │           └────────┬────────┘
     │                    ▼
     │           ┌────────────────┐
     │           │  风格融合模块   │
     │           │ Style Fusion   │
     │           └───────┬────────┘
     │                   │ 融合风格表征 S
     ▼                   ▼
┌──────────────────────────────┐
│     Transformer 解码器        │
│  (Cross-Attention + AdaIN)   │
│  内容特征 Fc 查询风格表征 S    │
└──────────────┬───────────────┘
               ▼
          风格化输出图像 I_out
```

**两个风格头的设计**：

| 头 | 输入 | 操作 | 输出 |
|----|------|------|------|
| **风格头** (Genre Head) | 风格图全局特征 | 跨图注意力 + 风格类别嵌入 | 全局风格代码（如"油画风格"的向量表示） |
| **实例头** (Instance Head) | 风格图局部特征 | 局部自注意力 + 纹理聚合 | 实例级风格代码（笔触、纹理的细粒度表示） |

**风格融合模块**：将两个头的输出拼接后通过轻量MLP融合，生成统一的条件风格表征 $S$，注入到Transformer解码器的Cross-Attention和AdaIN层中。

### 3.3 训练策略

- **对比学习框架**：将风格迁移视为表征学习问题
  - 正样本对：同一种风格的不同图像
  - 负样本对：不同风格的图像
- **双头联合训练**：两个风格头共享风格编码器骨干，同时优化
- **端到端**：内容编码器、风格编码器、双头、解码器联合训练

### 3.4 损失函数

$$L_{total} = L_{content} + \lambda_{style} L_{style} + \lambda_{contrast} L_{contrast}$$

- **$L_{content}$**：内容保持损失 → 通常使用预训练VGG的感知损失，确保生成图像保留原内容结构
- **$L_{style}$**：风格一致性损失 → 风格特征的Gram矩阵差异，确保全局+局部风格匹配
  $$L_{style} = \|Gram(F_s) - Gram(F_{out})\|_2^2$$
- **$L_{contrast}$**：对比损失 → 拉近同风格样本的双头表征，推远不同风格表征
  $$L_{contrast} = -\log\frac{\exp(sim(z_i, z_j)/\tau)}{\sum_{k\neq i}\exp(sim(z_i, z_k)/\tau)}$$
  其中 $z$ 为双头融合后的风格表征，$\tau$ 为温度参数

## 4. MLCNet: Multi-Task Level-Specific Constraint Network for Building Change Detection

**发表**：IEEE TNNLS 2024 | IF 10.4 | 作者：Taoyuan Liu, Jiepan Li, Fangxiao Lu, Minghao Tang, Guangyi Yang

### 4.1 动机

遥感影像建筑变化检测的挑战：
- **低层特征**具有空间分辨率优势（精确定位变化边缘），但语义模糊
- **高层特征**具有语义抽象优势（准确判断"是建筑变化还是其他变化"），但空间粗糙

传统单头解码器采用"一刀切"（One-size-fits-all）融合，要么边缘不准，要么语义错误。

### 4.2 网络结构

```
时序遥感图像 T1, T2
    │
    ▼
┌─────────────────┐
│   共享编码器      │  ← Siamese编码器，分别提取T1和T2特征
│ (Siamese Encoder)│
└────────┬────────┘
         │ 多尺度特征金字塔 {F1, F2, F3, F4}
         │  F1: 最高分辨率, 最低语义   (低层)
         │  F4: 最低分辨率, 最高语义   (高层)
         ▼
┌────────────────────────────────────────┐
│         多任务层级特定约束双头            │
│                                        │
│  ┌──────────────────┐ ┌──────────────┐ │
│  │  低层空间头        │ │ 高层语义头    │ │
│  │  Spatial Head     │ │ Semantic Head│ │
│  │                  │ │              │ │
│  │ 输入: F1, F2     │ │ 输入: F3, F4 │ │
│  │                  │ │              │ │
│  │ → 空间细节解码    │ │ → 语义抽象解码 │ │
│  │ → 边缘检测分支    │ │ → 变化分类分支 │ │
│  │ → 二值变化图      │ │ → 语义变化图   │ │
│  └────────┬─────────┘ └──────┬───────┘ │
│           │                  │         │
│           └────────┬─────────┘         │
│                    ▼                   │
│              ┌──────────┐              │
│              │ 特征融合  │              │
│              │  (晚期)   │              │
│              └─────┬────┘              │
└────────────────────┼───────────────────┘
                     ▼
              最终变化检测图
```

**层级特定约束的核心逻辑**：

| 特征层 | 优势 | 负责的头 | 输出 |
|--------|------|---------|------|
| F1, F2（低层） | 高空间分辨率，边缘清晰 | **低层空间头** | 变化边缘掩码、二值变化定位 |
| F3, F4（高层） | 强语义判别力，类别敏感 | **高层语义头** | 建筑语义变化分类、变化类型识别 |

### 4.3 训练策略

- **混合标签重构**：将原始真实值（Ground Truths）重构为三种互补标签：
  1. **语义标签**：建筑/非建筑/变化建筑（多类分割）
  2. **二值标签**：变化/未变化（二分类分割）
  3. **边缘标签**：变化区域的精确边界（边缘检测）
- **多任务联合训练**：
  - 低层空间头 → 监督：二值标签 + 边缘标签
  - 高层语义头 → 监督：语义标签
- 端到端优化，所有层级同步训练

### 4.4 损失函数

$$L_{total} = L_{sem} + \alpha L_{bin} + \beta L_{edge}$$

- **$L_{sem}$**：语义分割损失（多类交叉熵 + Dice Loss）
  $$L_{sem} = L_{CE}(y_{sem}, \hat{y}_{sem}) + L_{Dice}(y_{sem}, \hat{y}_{sem})$$
- **$L_{bin}$**：二值变化检测损失（Focal Loss，处理变化/未变化类别不平衡）
  $$L_{bin} = -\alpha_t(1-p_t)^\gamma \log(p_t)$$
- **$L_{edge}$**：边缘损失（对变化区域边界的L1约束，确保边缘精度）
  $$L_{edge} = \|Edge(y) - Edge(\hat{y})\|_1$$

> **关键**：三个损失分别对应三个层级的特定约束，而非笼统地平均——低层头侧重边缘，高层头侧重语义，由此实现层级间的高效分工。

## 5. Spatiotemporal Data Analytics and Modeling

**出版**：Springer 2024 | ISBN: 978-981-99-9651-3 | 专著

### 5.1 内容概述

这是一本系统介绍时空数据分析与建模的学术专著，覆盖从传统统计方法到现代深度学习技术的完整技术栈。

### 5.2 章节框架

| 主题 | 内容 |
|------|------|
| **时空数据基础** | 时空数据表示、索引结构、数据预处理 |
| **模式挖掘** | 时空聚类、频繁模式挖掘、异常检测 |
| **预测建模** | 传统时空统计（Kriging, STARIMA）→ 机器学习（RF, XGBoost）→ 深度学习（GNN, Transformer, 扩散模型） |
| **可视化与解释** | 时空数据可视化技术、模型可解释性 |
| **应用案例** | 交通流量预测、气象预报、流行病传播建模、城市计算 |

### 5.3 与双头网络的关联

书中讨论的多任务时空预测场景常采用双头/多头架构：
- **空间头**：建模空间依赖（如地理邻居的影响）
- **时间头**：建模时间依赖（如周期性、趋势）
- 两者在共享的时空编码器基础上独立输出，再融合得到最终的时空预测

这是双头架构在"时空"这一维度上的另一种解耦范式——不同于CV中的"去噪-重建"或"空间-频域"，而是"空间-时间"的解耦。

## 6. StarIR: Convolutional Image Restoration With Spatial-Frequency Fusion

**发表**：IEEE TPAMI 2026 | IF 20.8 | 作者：Yuning Cui, et al.

### 6.1 动机

通用图像恢复（去噪、去模糊、超分等）的传统方法大多只在空间域操作，忽略了频域信息的关键作用：
- **空间域**擅长捕获局部纹理、边缘、细节
- **频域**（傅里叶变换后）擅长捕获全局周期性模式、噪声分布、介观尺度交互

单域方法无法兼顾，StarIR通过空间-频域双分支融合实现突破。

### 6.2 网络结构

```
输入退化图像
    │
    ▼
┌─────────────────┐
│   共享浅层骨干    │  ← 初始特征提取
└────────┬────────┘
         │
    ┌────┴────┐
    ▼         ▼
┌────────┐ ┌────────┐
│空间域分支│ │频域分支 │
│Spatial │ │Freq.   │
│ Branch │ │ Branch │
│        │ │        │
│ • 卷积 │ │ • FFT  │
│   堆叠 │ │   变换  │
│ • 残差 │ │ • 频域  │
│   块   │ │   卷积  │
│        │ │ • IFFT │
│        │ │   逆变换│
│        │ │        │
│输出:   │ │输出:   │
│空间特征 │ │频域特征 │
│ F_s    │ │ F_f    │
└───┬────┘ └───┬────┘
    │          │
    └────┬─────┘
         ▼
┌─────────────────┐
│  Star Operation │  ← 高维特征融合
│  (星形操作)      │
│                 │
│  F_s ⊙ F_f     │  ← 逐元素乘 + 高维映射
│  将空间和频域    │
│  特征交汇融合    │
└────────┬────────┘
         ▼
┌─────────────────┐
│   重建解码器      │
└────────┬────────┘
         ▼
    恢复输出图像
```

**双分支详解**：

| 分支 | 数据通路 | 擅长捕获 | 输出 |
|------|---------|---------|------|
| **空间域分支** | 标准卷积堆叠 + 残差连接 | 局部纹理、边缘、像素级细节 | 空间特征图 $F_s$ |
| **频域分支** | FFT → 频域卷积（复数运算） → IFFT | 全局周期性模式、噪声分布、介观尺度交互 | 频域特征图 $F_f$ |

**Star Operation（星形操作）**：核心创新——不是拼接（维度翻倍）或相加（线性混合），而是将空间特征和频域特征通过**逐元素乘法（Hadamard积，符号 ⊙）**进行乘性交互：

$$F_{star} = F_s \odot F_f$$

展开到单个通道 $c$ 的单个位置 $(i,j)$：$F_{star}[c,i,j] = F_s[c,i,j] \times F_f[c,i,j]$

这一设计的精妙之处在于：

1. **频域门控空间**：$F_f[c,i,j]$ 大 → $F_s[c,i,j]$ 被放大（关注该位置的细节），$F_f[c,i,j]$ 接近0 → $F_s[c,i,j]$ 被抑制（该位置可能是噪声）。频域特征充当了空间特征的**软门控（soft gate）**。

2. **隐式高维交互**：反向传播时 $\frac{\partial L}{\partial F_s} = \frac{\partial L}{\partial F_{star}} \odot F_f$，$\frac{\partial L}{\partial F_f} = \frac{\partial L}{\partial F_{star}} \odot F_s$——每个分支的梯度被另一个分支的激活值缩放，等价于在更高维的交互空间中优化，建立两分支间的**双向依赖**，迫使网络学习空间-频域一致性表征。

3. **零参数增量**：逐元素乘法不引入任何可学习参数，维度保持 $C \times H \times W$ 不变，下游计算量几乎不增加。

> 一句话：用频域特征门控空间特征（反之亦然），不增参数不增维度，却实现了两域的非线性乘性交互。

### 6.3 训练策略

- **端到端联合训练**：两个分支和融合模块同步优化
- **多尺度监督**：在重建解码器的多个尺度上计算损失，逐级细化
- **通用恢复框架**：同一架构可处理去噪、去模糊、超分等多种任务，只需调整输入输出配置

### 6.4 损失函数

$$L_{total} = L_{spatial} + \lambda_f L_{frequency} + \lambda_p L_{perceptual}$$

- **$L_{spatial}$**：空间域像素级重建损失
  $$L_{spatial} = \|I_{gt} - I_{out}\|_1$$
- **$L_{frequency}$**：频域损失 → 分别约束幅值和相位
  $$L_{frequency} = \|Amp(F_{gt}) - Amp(F_{out})\|_1 + \|Phase(F_{gt}) - Phase(F_{out})\|_1$$
- **$L_{perceptual}$**：感知损失（VGG特征空间中的L2距离），提升视觉质量

## 7. TSD-SR: One-Step Diffusion with Target Score Distillation for Real-World Image Super-Resolution

**发表**：IEEE TPAMI 2025 | IF 20.8 | 作者：Linwei Dong, Qingnan Fan, Yihong Guo, Zhonghao Wang, Qi Zhang, Jinwei Chen, Yawei Luo, Changqing Zou

### 7.1 动机

扩散模型（Diffusion Models）在图像超分（Real-ISR）上效果好，但推理需要数十到数百步迭代，计算代价极高。知识蒸馏可以将多步模型压缩为一步，但存在"顾此失彼"的困境：

- 单判别器蒸馏 → 追求"空间细节真实度"则损失"时序一致性"，导致视频闪烁
- 追求"时序一致性"则过分平滑，丢失高频细节

TSD-SR通过**双头对抗蒸馏方案**彻底解耦这两个对抗目标。

### 7.2 网络结构

```
阶段一：目标分数蒸馏 (Target Score Distillation)
───────────────────────────────────────────────

预训练扩散教师模型 DOVE (DiT-based, 多步推理)
        │
        │ 目标分数蒸馏 (TSD)
        │ 提取扩散先验 + 真实图像参考
        ▼
    一步学生模型 (Student)
        │
        │  特征 → 上采样 → 超分图像
        ▼
    初始超分输出


阶段二：双头对抗蒸馏训练
───────────────────────────────────────────────

          一步学生模型
               │
               ▼
          超分输出图像
               │
    ┌──────────┼──────────┐
    ▼                      ▼
┌────────────┐      ┌────────────┐
│ 像素空间     │      │ VAE特征空间  │
│ 判别器 D1   │      │ 判别器 D2   │
│            │      │            │
│ ┌────┐┌────┐│      │ ┌────┐┌────┐│
│ │细节││一致││      │ │细节││一致││
│ │头  ││性头││      │ │头  ││性头││
│ └────┘└────┘│      │ └────┘└────┘│
│            │      │            │
│ 共享判别器  │      │ 共享判别器  │
│ 主干        │      │ 主干        │
└────────────┘      └────────────┘
```

**结构详解**：

| 组件              | 作用                                                                                   |
| --------------- | ------------------------------------------------------------------------------------ |
| **目标分数蒸馏（TSD）** | 从扩散教师模型中提取先验知识，结合真实图像参考，指导一步学生模型实现逼真恢复。不同于传统Score Distillation，TSD利用了真实高分辨率图像的目标分数信号 |
| **分布感知采样模块**    | 使细节导向梯度更容易获取，解决一步模型难以恢复精细细节的痛点                                                       |
| **像素空间判别器**     | 在RGB像素空间中判断图像真伪，评估空间质量                                                               |
| **VAE特征空间判别器**  | 在VAE解码器的潜在特征空间中判断，捕获更抽象的语义真实性                                                        |
| **细节头/一致性头**    | 两个判别器内部各有两个独立输出头，分别评估**空间细节真实性**和**时序帧间一致性**                                         |

### 7.3 训练策略

- **双空间双头对抗训练**：
  1. 学生模型生成超分图像
  2. 两个判别器分别在像素空间和VAE特征空间中评估
  3. 每个判别器的细节头计算"空间真实度"对抗损失
  4. 每个判别器的一致性头计算"时序连贯性"对抗损失
  5. 两个头共享判别器主干，但对抗损失独立优化
- **关键**：通过解耦对抗目标，空间细节和时序一致性不再互相撕扯
- **推理部署**：只需运行一步学生模型（无需扩散迭代），推理速度比原扩散模型快约 **40倍**，参数减少 **95%**

### 7.4 损失函数

$$L_{total} = L_{TSD} + \lambda_{adv} L_{adv} + \lambda_{rec} L_{reconstruction}$$

- **$L_{TSD}$**：目标分数蒸馏损失
  $$L_{TSD} = \mathbb{E}_{t,\epsilon}\left[\|\epsilon_\theta(x_t, t) - \epsilon_{student}(x_t, t)\|_2^2\right]$$
  其中 $\epsilon_\theta$ 为教师模型的分数估计，$\epsilon_{student}$ 为学生模型的分数估计

- **$L_{adv}$**：双头对抗损失
  $$L_{adv} = L_{adv}^{detail} + L_{adv}^{consistency}$$
  - 细节头对抗损失 $L_{adv}^{detail}$：评估空间细节真实性的GAN损失
  - 一致性头对抗损失 $L_{adv}^{consistency}$：评估时序连贯性的GAN损失
  - 两个损失独立计算、分别优化，避免冲突

- **$L_{reconstruction}$**：像素级重建损失
  $$L_{reconstruction} = \|I_{HR} - I_{SR}\|_1$$
  确保基本重建质量不退化

### 共同趋势洞察

2024-2026年顶刊双头网络已从"共享底部→各自输出"的简单模式演进为**"头间共生"**范式：

1. **从并行到头间交互**：PDHFormer的渐进式条件依赖、CANS的交叉注意力，头与头之间开始建立横向信息通路
2. **双头作为内生正则化器**：当特征空间被迫支持两个对抗性任务时，网络必须抛弃捷径特征，提炼本质表征——双头博弈本身就是一种正则化
3. **梯度冲突消解**：通过解耦头（DHO框架）、不确定性自适应加权（TwoHead-SwinFPN）、双头判别器（TSD-SR），将任务间的梯度冲突转化为互补增益
